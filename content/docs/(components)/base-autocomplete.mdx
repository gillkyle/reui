## API Reference

### Autocomplete

This component is based on the [Base UI Autocomplete](https://base-ui.com/react/components/autocomplete) primitive and includes the following custom props:

| **Prop**  | **Type**                                                                | **Default**   | **Description**                               |
| --------- | ----------------------------------------------------------------------- | ------------- | --------------------------------------------- |
| `variant` | ~enum~ <PopoverInfo> "default" \| "outline" \| "filled" </PopoverInfo> | ~"default"~   | The visual style variant of the autocomplete |

### AutocompleteInput

The input element for typing in the autocomplete.

### AutocompleteTrigger

A button that can toggle the autocomplete popup.

### AutocompleteClear

A button that clears the current value.

### AutocompleteIcon

An icon element, typically used to show a search or dropdown icon.

### AutocompletePopup

The popup container that holds the list of options.

### AutocompleteList

The scrollable list container for the options.

### AutocompleteItem

An individual option in the list.

### AutocompleteEmpty

Content shown when no options match the input.

### AutocompleteGroup

Groups related options together.

### AutocompleteGroupLabel

A label for a group of options.

### AutocompleteSeparator

A visual separator between groups or sections.

### AutocompleteValue

Renders the current value of the autocomplete.
